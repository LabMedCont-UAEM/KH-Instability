Python codes for Shear Instability, our model is based on the Orr-Sommerfeld equation, the unperturbed main flow moves by an electromagnetic force using a Quasi 2D model.
The file "Chebyv2.py" must to be in the same directory where "Lorentz_force_Q2D.py", "Lorentz_force_Q2D_free-slip.py" or "Qcrit.py" is located.

We run it on conda, library needed:
-SciPy (for linalg and "erf" function)
-Numpy (for trigonometric functions)
-Matplotlib (for graphs)
-csv (for saving)

Codes from our paper entitled "Electromagnetically generated shear instability in a narrow channel"
